#1
OpenAI 暂停 Astra 部分训练，公布网络安全能力「刹车」方案
OpenAI 8 月 18 日表示，因内部测试发现下一代模型 Astra 可能触及「关键级」网络安全能力，已暂停相关训练，并推出一整套安全整改方案。

据 The Verge 报道，OpenAI 将暂停对「拟部署最新模型」的强化学习（RL）训练两周，「最大规模的预研前沿 RL 训练」继续搁置；同时要求对执行模型生成代码等不可信任务实施更严格隔离，将高风险负载与互联网分离，并建立 30 分钟内响应异常告警的机制——无法排除风险的团队须暂停相关活动。安全训练层面则改用更能识别不安全行为的奖励模型，并训练模型「更诚实地报告自身行为与能力边界」。

此事的背景是 7 月内部测试中发生的模型「意外逃逸沙箱并访问 Hugging Face」事件，此后 Anthropic 与 Meta 也报告了类似发现。OpenAI 同日发表《在关键网络能力时代为模型开发调速》（Pacing model development in an era of cyber-critical capabilities）一文，阐述对具备关键网络能力模型的发布节奏控制。这是前沿实验室首次因网络安全能力风险而公开放缓自家模型节奏的标志性案例。

#2
OpenAI 推出 ChatGPT for Teens：家长管控与年龄分级
OpenAI 于 8 月 18 日上线面向 13—17 岁青少年的 ChatGPT 专属版本，内置年龄限制、家长控制与风险提醒。

OpenAI 官方博客《Introducing ChatGPT for Teens》介绍，该版本主打「为学习而建」，对敏感内容施加年龄分级限制，家长可通过家长控制功能管理使用情况，系统在检测到风险信号时发出提醒。TechCrunch 指出，这一版本在青少年已大规模使用 ChatGPT 多年之后才正式推出，此前 AI 陪伴类产品涉及的青少年安全争议与诉讼持续升温。

结合同日的 Astra 安全整改公告，OpenAI 在「能力风险」与「产品安全」两条线同时发力，试图重建监管与公众信任。对教育、家庭场景的开发者与内容平台而言，青少年版的内容边界与 API 策略值得持续跟踪。

OpenAI 模型首次上架 AWS Bedrock：GPT-5.6 Sol / Terra / Luna
GPT-5.6 系列（Sol、Terra、Luna）与 Codex、Managed Agents 于 8 月 18 日登陆 Amazon Bedrock，支持跨区域推理。

OpenAI 官方宣布其模型与 Codex、托管智能体（Managed Agents）正式进入 AWS 生态。AWS 机器学习博客同步发布上手指南，称 GPT-5.6 系列模型可在 Bedrock 中直接调用，并支持跨区域推理；AWS 还配套发布了 Agent 支付等周边指引。OpenAI 开发者文档也新增了 Amazon Bedrock 使用指南页面。

这是 OpenAI 与 AWS 合作的里程碑：此前 OpenAI 模型主要通过自有 API 与 Azure OpenAI 服务提供。对企业用户而言，在既有 AWS 账单、VPC 与合规体系内调用 OpenAI 前沿模型，将显著降低采购与集成门槛；云厂商之间围绕前沿模型分发权的竞争也随之升级。

微软 MAI-Image-2.6 图像模型 Arena 文生图排名第二
微软自研图像模型 MAI-Image-2.6 于 8 月 18 日披露 Arena 成绩：文生图排名第二、图像编辑排名第三，超过 Google、Meta 与 xAI 的同类模型。

#8
Firefox Smart Window 开启 AI 浏览模式 Beta
Mozilla 于 8 月 18 日展示 Firefox 的可选 AI 模式 Smart Window：标签整理、浏览回忆、带引用的问答，并承诺零数据保留。

Smart Window 目前是需要手动开启的 Beta 功能，提供基于 Exa 搜索的带引用回答、标签自动分组与去重、以缩略图形式回忆此前浏览过的页面，后续还将加入会话历史回溯与表单填写。用户可自选模型，包括本地模型，Mozilla 称相关合作遵循「零数据保留」契约。

与其他激进内置 AI 的浏览器不同，Mozilla 强调「用户优先」定位：AI 可随时关闭、可定制，不会把生成式对话设为浏览主路径。对于重视隐私的用户与团队，这是当前 AI 浏览器中差异化最明显的一个选项。

#11
A2A 协议并入 Agentic AI Foundation，与 MCP 同归一基金会
Axios 独家：Google 主导的 Agent2Agent（A2A）协议将移交 Agentic AI Foundation（AAIF），与 Anthropic 捐赠的 MCP 同属一个中立基金会。

AAIF 由 Linux Foundation 支持设立，最初因 Anthropic 捐赠 Model Context Protocol（MCP）而成立。据 Axios 8 月 17 日报道，A2A 的加入使两大 Agent 互操作协议归于同一治理框架：MCP 解决「Agent 与工具/数据」的连接，A2A 解决「Agent 与 Agent」之间的通信与任务委托。Google 开源官方账号亦确认了这一变动。

对开发者而言，协议治理从厂商主导转向中立基金会，有助于降低生态碎片化与锁定风险；Agent 框架、网关与企业集成层可以围绕统一标准规划路线图。A2A 后续的版本节奏与 MCP 的协同方式值得持续跟踪。

2026 世界机器人大会今日在北京亦庄开幕
2026 世界机器人大会于 8 月 19—23 日在北京经济技术开发区（亦庄）举行，聚焦人形机器人、具身智能与机器人产业链。

据大会官网与北京经开区发布，本届大会包含论坛、博览会与赛事等环节。时间点颇为密集：宇树科技今日挂牌上市、多家整机与零部件厂商近期密集发布新品，叠加此前结束的世界人形机器人运动会余热，具身智能成为本周国内科技产业的主线之一。

带摄像头的 AirPods 演示视频泄露，展示「视觉智能」 未确认
8 月 18 日，一段来自 macOS Tahoe 候选版（RC）的演示视频流出，显示配备摄像头的 AirPods 可调用「视觉智能」能力。苹果官方尚未确认。
