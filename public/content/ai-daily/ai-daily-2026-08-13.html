#1
Google 宣布 Gemini 应用月活突破 10 亿
Sundar Pichai 表示 Gemini 应用月活用户已超过 10 亿，成为 Google 增长最快的产品。

Pichai 于 8 月 11 日宣布 Gemini 应用月活跃用户突破 10 亿，是 Google 第 14 个达到该规模的产品，也是其中增长最快的一个。据报道，63% 的用户使用语音交互，每日生成图片超过 1.5 亿张，iOS 端活跃用户超过 1 亿。

作为参照，ChatGPT 已于今年 6 月达到 10 亿月活，Gemini 晚了约两个月。两大消费级 AI 应用先后进入「十亿俱乐部」，标志着 AI 助手正式成为主流消费入口。

#5
OpenAI 发布 GPT-5.6-Cyber，Daybreak 扩展至 Blue / Red 双层
OpenAI 推出面向安全研究的 GPT-5.6-Cyber，在受控访问下放宽对高风险双用途网络安全任务的限制。

8 月 11 日，OpenAI 发布 GPT-5.6-Cyber——一个衍生自 GPT-5.6 Sol 的安全专用模型，面向漏洞研究、渗透测试与应急响应。该模型在受限访问下减少对特定高风险、双用途网络安全任务的拒绝。Daybreak 计划随之扩展为两层：Daybreak Red 面向获批组织开放专用安全模型，Daybreak Blue 面向授权防御性安全工作开放通用前沿模型。

OpenAI 公布的内部测试显示，GPT-5.6-Cyber 在高级网络安全测试中完成率达 95.0%，而 GPT-5.6 Sol 为 1.5%、Daybreak Blue 为 2.0%、上一代 GPT-5.5-Cyber 为 57.3%。这是前沿实验室中少见的「明确为攻击性安全能力放宽限制」的产品化尝试，访问门槛与合规审核成为关键约束。

#6
Meta 开源 Muse Glimmer：30B Apache 2.0 智能体模型
Meta 以 Apache 2.0 协议开源 30B 稠密多模态模型 Muse Glimmer，主打本地 Agent、编程与评审场景。

Meta 于 8 月 10 日开源 Muse Glimmer：30B 参数稠密多模态模型，采用 Apache 2.0 协议，面向本地智能体、编程和评审（judge）场景。规格方面：131K 上下文、支持 100 多种语言，4-bit 量化后可装入 20GB 以下显存，在 RTX 5090 上报告有 3.1 倍加速。

Meta 同时承诺将开源 Muse Spark 1.2，并设立 10 亿美元社区基金。在 Muse 系列转向闭源争议之后，Glimmer 被视为 Meta 重新回到开源路线的信号。

#7
英伟达发布 Nemotron 3.5 Lightning 与 NeMo Switchyard
英伟达推出 30B MoE 开源模型 Nemotron 3.5 Lightning 和路由库 NeMo Switchyard，主打低成本高速的本地 Agent 推理。

英伟达 8 月 11 日发布 Nemotron 3.5 Lightning：30B 总参数、3B 激活参数的 MoE 模型，官方称在可比性能下输出速度最高提升 4 倍，部分端点约 670 tokens/s。同时开源 NeMo Switchyard 路由库，按任务将请求分发到更便宜的模型以降低成本——Cognition 称其 Devin Desktop 平均成本下降 28%。

中文媒体报道称，在 RTX 5090 上运行相关模型可达约 200 tokens/s，成本降低约 67%。这一组合延续了英伟达「把推理成本打下来、把生态留在 DGX/RTX 上」的策略。

xAI 与 Cursor 推出 Grok Bot 智能体应用 Beta
Grok Bot 以「7×24 在线的 AI 队友」为卖点，每个 Bot 拥有独立云端电脑，可登录真实服务并完成多步骤任务。

OpenAI 发布 ChatGPT 桌面应用 Linux 预览版，覆盖 Ubuntu / Debian / Fedora，内置 Codex。

8 月 11 日，OpenAI 发布 ChatGPT 桌面应用的 Linux 预览版，支持 Ubuntu 24.04 / 26.04 LTS、Debian 13 与 Fedora 43 / 44，覆盖 x64 与 ARM64 架构。应用包含 ChatGPT、ChatGPT Work 与 Codex，其中 Codex 可直接操作本地代码仓库、终端和文件夹。

#12
Claude Code 明日起默认开启 Auto Mode 自动批准
自 8 月 14 日起，Claude Code 对 Pro / Max / Team 用户默认启用自动批准，由安全分类器把关不可逆操作。

Anthropic 宣布，自 8 月 14 日（明日）起，Claude Code 的自动批准模式（Auto Mode）将成为 Pro、Max 和 Team 用户的默认设置。系统会用分类器审查不可逆或破坏性的工具调用；内部测试显示该分类器可拦截 89% 的危险命令，而人工审查的拦截率仅 13.6%。使用该模式的团队 PR 产出约提升 25%，分类器消耗的额外 token 免费。

这是 AI 编程工具从「每步确认」走向「自动执行 + 异常拦截」的重要节点。建议开发者留意默认行为变化，按需调整权限配置。

#13
OpenWALDO 启动：让 AI 训练数据可审计
Rocky Linux 创始人 Gregory Kurtzer 发起 OpenWALDO，尝试为 AI 训练数据建立「物料清单」式的来源追踪。

8 月 11 日，Rocky Linux 创始人 Gregory Kurtzer 发起社区项目 OpenWALDO，目标是让 AI 训练数据变得可审计。其参考语料库包含约 1240 亿参考 token、7510 万份文档，并提供类似软件物料清单（SBOM）的来源追踪机制。

在版权诉讼与数据合规压力持续上升的背景下，「数据出处可证明」正成为开源社区的新基础设施方向。该项目能否成为事实标准仍有待观察，但思路值得关注。

#14
Cloudflare 发布为 Agent 而生的浏览器 Kitesurf
Cloudflare 推出托管式 Agent 浏览器 Kitesurf，运行在 Workers V8 隔离环境中，据称内存占用远低于 Chromium。

Cloudflare 于 8 月 8 日发布了为 AI Agent 设计的托管浏览器 Kitesurf，运行在 Workers V8 隔离环境中，由多个组件在 12 周内构建完成，可通过约 21.5 万项 Web 平台测试。官方与第三方报道称其 CPU 与内存占用明显低于 Chromium（The Next Web 称内存约为其 1/7）。

Kitesurf 现通过 Browser Run 免费 Beta 开放。「浏览器即 Agent 运行时」正在成为云厂商的新战场，对做浏览器自动化和网页 Agent 的团队值得试用评估。
