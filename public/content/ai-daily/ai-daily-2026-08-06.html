腾讯云开源 TencentDB-Agent-Memory：团队级 Agent 记忆中枢登上 GitHub 趋势榜

腾讯云开源的「团队级 Agent 记忆中枢」本周冲上 GitHub 趋势榜（周增约 5400 star），主打多 Agent 共享的分层记忆层。

该项目把对话、文档与代码沉淀为 Chat Memory、Skill、LLM-Wiki、Code-Graph 四类资产，采用 L0 对话 → L1 原子 → L2 场景 → L3 人格的分层记忆结构，检索侧结合 BM25、向量检索与 RRF 融合排序，并提供可见性控制（private / team / restricted / agent）。Agent 通过标准工具接口（/v3/tools/list、/v3/tools/call）发现与调用记忆能力。

项目文档显示其已适配 OpenClaw、Hermes、Claude Code、CodeBuddy 等编程 Agent 生态，并提供 SDK。团队版（Team Memory Beta）仍在快速迭代。在多 Agent 协作场景中，「共享记忆」是当前工程落地的明显短板，大厂下场做标准化记忆层值得关注。
