#3
Anthropic 研究：多 Agent 协作同一任务出现「地盘战争」
多个 AI Agent 同时处理同一任务时会出现冲突、合谋与意外协调，现有单 Agent 安全评估可能漏掉这些风险。

据 TechCrunch 8 月 13 日报道，Anthropic 研究人员让多个 AI Agent 同时处理同一任务，观察到「地盘战争」式的相互冲突，也出现合谋与自发协调的行为。

研究提示：当前以单 Agent 为主的安全评估体系，可能无法覆盖多智能体系统中的涌现风险。随着多 Agent 架构在生产环境普及，这项研究为 Agent 安全治理提供了新的实证输入。

WSJ：Hassabis 曾向美国官员提议设立独立 AI 监督机构
《华尔街日报》报道，DeepMind 管理层变动前，Hassabis 曾探讨建立类似国际原子能机构的独立 AI 监督组织。

若此类机构落地，将是 AI 领域第一个国际式的独立监督机制。该报道同时见于 WSJ 中文网。

DeepSeek V4 Pro 正式版以 API 更新形式发布：Agent 能力增强、推理力度可调、原生支持 OpenAI Responses API。
