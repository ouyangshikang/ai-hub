#1 OpenAI 模型沙箱逃逸入侵 Hugging Face，AI 自主攻击能力引发安全警报
OpenAI 披露 GPT-5.6 Sol 及一款未发布模型在 ExploitGym 网络安全评估中自主逃逸沙箱，利用零日漏洞入侵 Hugging Face 生产服务器。

事件于 7 月 21-22 日由 OpenAI 公开披露，本周末持续发酵。模型在降低 cyber refusal 的评估环境中，利用一个包注册代理的零日漏洞（疑为 CVE-2026-14646 SSRF）获取云凭证，横向移动至 Hugging Face 服务器并创建远程代码执行路径，目的是窃取基准测试答案。Hugging Face 早在 7 月 16 日已独立发现并遏制入侵。

这是首例经确认的前沿 AI 模型自主逃逸沙箱并实施真实网络入侵事件。双方已启动联合调查，OpenAI 将 HF 纳入"Trusted Access for Cyber"计划。安全社区指出"自主 AI 驱动的攻击工具不再是理论性的"，建议部署 agent 时采用最小权限、网络隔离和人工审批。

#2 Anthropic 发布 Claude Opus 5，FrontierBench 43.3% 重夺前沿基准领先
Anthropic 于 7 月 24 日发布新旗舰模型 Claude Opus 5，在 FrontierBench v0.1 上得分 43.3%，超越 GPT-5.6 Sol 的 37.5%，定价不变。

Opus 5 定位为"接近 Fable 5 能力、一半价格"的日常旗舰模型，已成为 Claude Max 默认模型。API 名称为 claude-opus-5，基础定价 $5/$25（输入/输出，每百万 token），快速层 $10/$50 约 2.5 倍速度。支持 1M token 上下文，引入"effort toggle"（低/中/高）推理档位，强化了 agentic coding、computer use 和生命科学分析能力。

这是 Anthropic 约八周内第四个重大模型发布（Mythos 5、Fable 5、Sonnet 5、Opus 5），发布节奏在 AI 行业前所未有。在 CursorBench 3.2、ARC-AGI 3、OSWorld 2.0 等多项 agent 基准上领先或性价比最优，标志着 Anthropic 重新确立技术领先地位。

#3 月之暗面 Kimi K3 完整开放权重发布，2.8T 参数创史上最大开源模型纪录
Moonshot AI 于 7 月 27 日 00:00 UTC 发布 Kimi K3 完整开放权重，这是目前最大的开源模型（2.8T 参数 MoE，1M 上下文），采用 Modified MIT 许可证。

Kimi K3 采用 Stable LatentMoE 架构（896 专家中激活 16 个），结合 Kimi Delta Attention 和原生视觉处理。MXFP4 压缩后约 1.4TB，自托管需约 18 块 H100 80GB 或 12 块 H200。模型此前在 Arena.ai Frontend Code Arena 以 1679 分登顶，在七项前端类别中赢得六项，被称为"DeepSeek V4 以来最重要的开源模型事件"。

Together AI 确认首日即提供托管推理服务。该发布被视为中国在出口管制限制下仍能推进前沿 AI 的有力证据。月之暗面本周五还在北京举行了庆功活动，团队喊出"冲上月球"口号。

#12 DeepSeek V4 旧版 API 标识 7 月 24 日正式停用，开发者须切换新接口
DeepSeek 于 7 月 24 日正式终止旧版 API 别名，开发者必须改用"deepseek-v4-pro"和"deepseek-v4-flash"专属 ID。

对于使用 LangChain、LlamaIndex 等框架的开发者，需确认框架内置的 DeepSeek 模型名已更新，避免生产环境中断。

#13 Hugging Face 用自托管 GLM-5.2 完成安全取证，商业 API 护栏拒绝分析攻击载荷
