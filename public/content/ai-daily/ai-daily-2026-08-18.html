#1
Anthropic 年化营收飙升至 $650 亿，两个月新增 $180 亿
TechCrunch 报道，Anthropic 年化营收已达 $650 亿，两个月内新增 $180 亿年化收入。

TechCrunch 8 月 17 日报道称，Anthropic 的年化（run-rate）营收已升至 $650 亿。多家聚合信息的统计显示，该数字今年 5 月约为 $470 亿、去年底约为 $90 亿，意味着其营收在半年多时间里增长数倍，企业级 API 与编程场景被普遍视为核心驱动力。

营收的快速增长也在强化市场对 Anthropic 上市的预期（Fortune 曾报道其或于 10 月 IPO，见 #24）。Anthropic 官方暂未对该营收数字公开置评，具体数据以公司后续披露为准。

Stripe 敲定逾 $70 亿收购模型路由平台 OpenRouter
彭博 8 月 16 日报道交易接近达成后，多家媒体 8 月 17 日称 Stripe 收购 OpenRouter 的交易已敲定，金额超 $70 亿。

OpenRouter 聚合了数百个大模型的 API 端点，提供统一计费与路由，是开发者社区最常用的模型聚合入口之一。Stripe 高价将其收入囊中，被解读为把「模型路由 + 支付」纳入同一基础设施，为 AI 时代的 API 计费与 Agent 支付场景提前卡位。

这是支付巨头对 AI 开发者工具规模最大的一笔收购之一。交易细节以双方官方披露为准。

字节跳动 Seed 与清华 AIR 提出 CUDA Agent：用 RL 自动写 CUDA 内核
字节跳动 Seed 与清华 AIR 发布 CUDA Agent，一个大规模 Agentic RL 系统，可自主生成 CUDA GPU 内核，在 KernelBench 96.8% 的任务上优于 torch.compile。

该系统采用智能体式强化学习范式，让模型自主编写、剖析并迭代 CUDA 内核，在 KernelBench 基准上平均提速 2.11 倍。

这代表了「AI 构建 AI 基础设施」方向的进一步落地：传统上高度依赖专家手工优化的 GPU 内核开发正在被自动化。这也是过去 24 小时内中国团队在 AI-for-Infra 方向的代表性研究产出之一。

#12
LangChain 发布 AgentCore Payments：Agent 预算化支付中间件
LangChain 发布 AgentCore Payments 中间件，让 Agent 在确定性会话预算内为 API 付费：基础设施级限额、x402 微支付、全程可追溯。

该中间件基于 Amazon Bedrock AgentCore Payments，提供钱包认证、交易限额与支付签名。当 Agent 调用付费 API 时，中间件按会话预算核验费用、签名支付并重试请求，每笔交易写入 LangSmith 追踪记录。

与「用提示词约束花钱」不同，预算控制落在基础设施层，可靠性显著提升。Agent 经济的支付与计费基础设施正在走向成熟。

#13
Microsoft Research Webwright：Web Agent 应写代码而非点 UI
微软研究院主推的 Webwright 路线认为：Web Agent 优先「写代码调工具」比「模拟 UI 点击」更稳健高效。

文章分析了代码驱动的 Web Agent 在复杂任务上优于像素/点击驱动方案的原因：代码可组合、可重试、可验证，且不受 UI 变化影响。

这一路线与近期终端式、代码优先 Agent 的趋势一致，为浏览器 Agent 的架构选型（视觉点击派 vs 代码优先派）提供了工程参考。
